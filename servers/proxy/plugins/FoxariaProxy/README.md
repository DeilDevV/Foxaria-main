## FoxariaProxy plugin (Bungee-side)

Эта папка подготовлена под новый сетевой плагин, который заменит backend-модули:
- регистрацию/логин
- привилегии/префиксы
- общие сетевые проверки до входа в игровой backend

### Текущее состояние
- Старые `auth/ranks` вырезаны из backend bootstrap.
- `servers/game` оставлен игровым сервером.
- `store` (ресурсы/токены) остаётся на `servers/game`.
