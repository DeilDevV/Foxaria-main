# Foxaria — тестовый сервер

Локальный запуск **Paper 1.21.11** с плагином Foxaria.

Исходный код плагина лежит **уровнем выше** (папка `Foxaria-main` с модулями `foxaria-*`) — его нельзя удалять, если нужна сборка `Foxaria.jar`. См. `../README.md` в корне репозитория.

## Быстрый старт

1. Собери плагин из корня репозитория: `gradlew.bat :foxaria-bootstrap:shadowJar` (нужна **JDK 17+**).
2. Скопируй артефакты: запусти **`update-foxaria.cmd`** в этой папке (кладёт `Foxaria.jar` и конфиги в `plugins\`).
3. Запуск: **`start-servers/game.bat`**.

## Где лежат настройки Foxaria

Всё, что относится к плагину, в одном месте: **`plugins\Foxaria\`**

- `config.yml` — общие опции
- `messages.yml` — тексты сообщений
- `modules\*.yml` — модули (экономика, аукцион, регионы, UI и т.д.)

Настройки самого Paper остаются в **`config\`**, **`server.properties`** — это нормально для любого сервера.

## Прочее

- В тесте часто `online-mode=false`; для продакшена включи `online-mode=true` и отдельный профиль мира.
