## Proxy (BungeeCord) для Foxaria

Эта папка — **прокси-сервер**, который принимает игроков и перекидывает их на нужные backend-сервера.

### Зачем нужен прокси
- **Единая точка входа** (один IP:порт для игроков).
- **Единая авторизация**: игрок всегда попадает на `auth`, а уже после логина/регистрации — на `lobby`.
- **Общие системы** (в будущем): единые данные доната/прав, привязки Telegram/Discord, SSO для сайта, перенос предметов между серверами и т.п.

### Важно про безопасность (обязательно)
Прокси работает корректно и безопасно только если:
- backend-сервера **не принимают игроков напрямую из интернета** (закрыть порты в firewall / слушать только localhost/внутреннюю сеть)
- backend-сервера настроены под прокси:
  - `online-mode=false`
  - `bungeecord=true` (Spigot/Paper)
  - корректный `forwarding` (у Bungee это `ip_forward: true`)

### Что где менять
- `config.yml`
  - **listeners[0].host**: IP:порт прокси (обычно `0.0.0.0:25565`)
  - **servers.auth**: адрес auth-сервера (backend)
  - **servers.lobby**: адрес lobby-сервера (backend)
  - **priorities**: порядок серверов, куда пускать при входе/фолбэке

### Запуск
1) Нужна Java 21+ (или хотя бы 11+ для Bungee, но под твою сборку лучше 21).
2) Скачай BungeeCord jar (один файл) и положи рядом с `config.yml` под именем `BungeeCord.jar`.
3) Опционально: положи JDK в `servers/proxy/jdk` (тогда стартовые скрипты возьмут её автоматически).
4) Запусти:
   - Windows: `start-proxy.bat`
   - PowerShell: `start-proxy.ps1`

### Схема портов по умолчанию (можно менять)
- Proxy: `25565`
- Auth backend (`servers/auth`): `25566`
- Lobby backend: `25567`
- Game backend (`servers/game`): `25568`
