# Пример GUI flow

## Серверный магазин
1. Игрок вводит `/shop`
2. Открывается меню категорий
3. Игрок выбирает категорию
4. Открывается список товаров
5. ЛКМ покупает, ПКМ продаёт, если продажа включена
6. Проверка покупки идёт async, а выдача предмета происходит sync на main thread

## Аукцион
1. Игрок вводит `/ah`
2. Открывается браузер активных лотов
3. Игрок покупает лот
4. Лот переводится из `ACTIVE` в `SOLD` одной SQL-операцией
5. Предмет выдаётся игроку или уходит в mailbox, если инвентарь заполнен

## Магазины игроков
1. Игрок вводит `/pshop`
2. Открывается общий список витрин
3. `/pshop mine` открывает собственную витрину
4. `/pshop sell <price>` выставляет предмет из руки
5. Покупатель кликает по лоту
6. Остаток уменьшается атомарно
7. Продавец получает выплату после налога

## Панель модерации
1. Стафф вводит `/modpanel`
2. Открывается dashboard с жалобами и профилями игроков онлайн
3. Модератор открывает профиль подозрительного игрока
4. Быстрые действия дают freeze, mute, tempban, invsee, echest, teleport
5. Связанную жалобу можно закрыть прямо из профиля

## Админ-панель
1. Админ вводит `/adminpanel`
2. Открывается dashboard
3. Админ выбирает игрока
4. Быстрые кнопки дают доступ к экономике, наказаниям, рангам и аудит-данным

## Кейсы
1. Игрок вводит `/crate`
2. Открывается список кейсов
3. Игрок смотрит превью кейса
4. `/crate open <crateId>` расходует отслеживаемый ключ
5. Выполняется reward action
6. Открытие записывается в `fx_crate_open_logs`
