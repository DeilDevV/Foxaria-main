# EULA-conscious монетизация

## Безопасный фокус
- косметика
- теги
- титулы
- chat flair
- particle trails
- queue priority
- небоевые QoL-фичи
- сезонные косметические пропуски

## Спорные функции, требующие ручной проверки
- донатное преимущество в PvP
- усиленные наборы, влияющие на бой
- эксклюзивный доступ к ресурсам
- не-косметические power crates
- donor-only utility для рейдов, меняющая core balance

## Рекомендация по витрине магазина

Публичные страницы магазина лучше делить на:

1. Косметика
2. QoL
3. Подписки
4. Приоритет очереди
5. Статус / поддержка проекта
6. Позиции, требующие ручной проверки
