# Базовый Paper baseline

## Общие правила
- держать мир долгоживущим и не завязывать прогрессию на вайпы без отдельной бизнес-причины
- сперва использовать Paper-level лимиты и оптимизации, а не хаотичные plugin hacks
- server-level anti-xray предпочтительнее случайных костылей

## Геймплей
- PvP включён
- griefing включён
- claim-плагины не ставятся в базовый semi-anarchy профиль
- политика крыши Незера проверяется через конфиги Foxaria

## Производительность
- сначала тюнить entity/hopper/redstone limits средствами Paper
- профилировать через `spark`, а не гадать
- любые packet-heavy интеграции проверять под нагрузкой

## Безопасность
- protections для book/sign payload должны быть включены
- command rate limiting должен быть включён
- exploit blacklist нужно пересматривать после крупных обновлений

## Коммерция
- монетизация строится вокруг косметики, QoL, очереди и подписок
- chargeback/revoke flows должны быть проверены заранее
- каждая donor-выдача должна быть видна через `fx_tebex_fulfillments` и `fx_audit_log`
